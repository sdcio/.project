# Security Policy

## Reporting Security Issues

The sdcio maintainers take security seriously. We appreciate your efforts to responsibly disclose your findings.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them through our [private vulnerability reporting](https://github.com/sdcio/sdcio/security/advisories/new) form.

For more details, see the [sdcio security policy](https://github.com/sdcio/sdcio/blob/main/SECURITY.md).
